- Live hub: https://wadebrower792.github.io/lee-brower-store/

- Live store: https://wadebrower.gumroad.com

## Hosting (GitHub Pages)

After this repo is created, enable Pages once: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.**
The page then lives at https://wadebrower792.github.io/lee-brower-store/
