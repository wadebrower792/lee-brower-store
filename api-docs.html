ContractorOS

API Documentation

The endpoint surface of ContractorOS — the voice-first operating system for contractors, built by a working superintendent and live on real jobs today. API version 0.2.0 · 169 endpoints.

How this API is hosted: ContractorOS is deployed per customer — the API runs with each ContractorOS deployment (the native Android app and web office talk to it). There is no public sandbox host at this time; this page documents the API surface of the product so integration partners can evaluate it. Routes sit under /api (the health check and authenticated file delivery sit at the root) and, except the marked public, requires a JWT bearer token from POST /api/auth/login (OAuth2 password flow).
Integration status — Trimble ProjectSight: the connector to ProjectSight is planned, not yet built. The daily-log, document, and punch-item endpoints documented below are the ContractorOS side of that planned sync — the field record that will flow into the project system of record once the connector is built through Trimble's Technology Partner sandbox and certification path. No ProjectSight endpoints exist in ContractorOS yet, and none are documented here.
